# Специфікація для творців слів зарьми

Ти створюєш слова для штучної мови **Зарьма**. Перед роботою ОБОВ'ЯЗКОВО прочитай:
- `/home/user/dia/zarma/README.md` — абетка, правопис, граматика;
- `/home/user/dia/zarma/slovnyk.md` — вже існуючі ~250 слів (НЕ створюй їх повторно і НЕ використовуй ці форми для інших значень).

## 1. Дозволені літери (тільки ці!)
а б в г д е ѣ ж з и й к л м н о ѫ п р с т у х ц ч ш ѳ ы ь ъ

ЗАБОРОНЕНО: і ї є я ю щ ф ґ ' (апостроф), латиниця, дефіси всередині слова, пробіли всередині слова.
Замість я/ю/є/ї пиши йа/йу/йе/йи. Замість щ → шч. Замість ф → ѳ.

## 2. Як має звучати слово
- Мова має бути **непрозорою** для українця: звичайна людина не повинна вгадувати значення.
- Можна запозичувати слов'янські корені (укр., польськ., чеськ., болг., сербськ., старослов'янськ.), АЛЕ змінюй їх щонайменше двома способами (заміна голосної на ѣ/ѫ/ы, зміна приголосної, обрізання, перестановка, додавання суфікса). Приклад: *вода → ѳаль* (вигадано), *дім → дымо*, *серце → срѣдо*.
- Приблизно 50–60% слів — ПОВНІСТЮ ВИГАДАНІ корені (як *мырк* — кіт, *кѣпа* — дощ, *ѳамир* — родина).
- Часто використовуй ѣ, ѫ, ѳ, ы — це «обличчя» мови.
- Довжина кореня: 1–3 склади. Слова мають бути вимовними (не більше 3 приголосних підряд).
- Наголос завжди на передостанньому складі — враховуй милозвучність.

## 3. Частини мови та закінчення
| Позначка | Частина мови | Правило |
|---|---|---|
| ім | іменник | будь-яке закінчення, але НЕ на -ѫн |
| дс | дієслово | ЗАВЖДИ закінчується на **-ѫн** |
| пр | прикметник | будь-яке, часто -ѣ, -ав, або приголосна |
| присл | прислівник | часто прикметник + **-ши**, або окремий корінь |
| займ, числ, спол, част, вигук, післ | службові | будь-яке |
| вираз | стійкий вираз/ідіома | кілька слів через пробіл (тут пробіл дозволено) |

Словотвірні суфікси (використовуй їх, щоб робити родини слів від своїх коренів):
- `-ода` — абстрактний іменник (любода — любов)
- `-ар` — особа, яка діє (зарьар — мовець)
- `-ик` — зменшувальне
- `-иш` — місце (учиш — школа)
- `-ав` — прикметник з іменника
- `-ши` — прислівник
- `жа-` — заперечення/протилежність (жапомнѫн — забувати)
- `ѳо-` — завершена дія (ѳовидѫн — побачити)
- `ъ` — між префіксом на голосну і коренем на голосну (ѳоъискѫн)

## 4. СИНОНІМИ та ПАРОНІМИ — обов'язково!
- Для частих понять створи 2–4 **синоніми** з різними відтінками: нейтральне / поетичне / розмовне / зневажливе / офіційне. Кожен синонім — окремий рядок, у колонці `стиль` вкажи відтінок, у колонці `синоніми` — інші зарьмські слова групи.
- **Пароніми**: іноді свідомо створюй пари слів, схожих за формою, але різних за значенням (напр. *ѳалин* «криниця» і *ѳѣлин* «сокира»). У колонці `примітка` пиши `паронім: <слово>`.
- Омоніми (однакова форма — різні значення) НЕ створюй.

## 5. Формат виводу — TSV (розділювач — символ табуляції)
Файл: `/home/user/dia/zarma/data/raw/<тема>.tsv`, кодування UTF-8.
Перший рядок — заголовок рівно такий:
```
зарьма	чм	українська	стиль	синоніми	примітка
```
- `зарьма` — слово (малими літерами, крім власних назв);
- `чм` — частина мови (позначка з таблиці вище);
- `українська` — переклад; кілька значень через `; `;
- `стиль` — нейтр / поет / розм / зневаж / офіц / застар / наук / дит (порожньо = нейтр);
- `синоніми` — зарьмські синоніми через `, ` (або порожньо);
- `примітка` — етимологія (напр. `від укр. серце`, `вигадане`, `від кореня зарь`), паронім, приклад.

Приклад:
```
зарьма	чм	українська	стиль	синоніми	примітка
мырк	ім	кіт	нейтр	мьаур	вигадане
мьаур	ім	котяра; кіт	розм	мырк	звуконаслідувальне
мыркик	ім	кошеня	нейтр		від мырк + -ик
ѳалин	ім	криниця	нейтр	ѳальиш	від ѳаль; паронім: ѳѣлин
```

3. Пиши файл частинами (по 100–150 рядків за раз — дописуй у кінець через Bash `cat >> файл <<'EOF'`), щоб не втратити роботу.
4. Наприкінці перевір свій файл скриптом:
   `python3 /home/user/dia/zarma/data/check.py /home/user/dia/zarma/data/raw/<тема>.tsv`
   і виправ усі помилки, які він покаже (заборонені літери, дублікати, дієслова без -ѫн, неправильна кількість колонок).
5. У відповіді дай лише коротко: кількість рядків і 5 прикладів.

НЕ комміть у git. НЕ змінюй інші файли, окрім свого .tsv.
