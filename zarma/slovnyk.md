# Словник зарьми

Дієслова подано в словниковій формі на **-ѫн**. Прикметники не змінюються. Граматику описано в [README.md](README.md).

## Словотвір

| Частина слова | Значення | Приклад |
|---|---|---|
| -ѫн | дієслово (інфінітив) | *любѫн* — любити |
| -ода | абстрактний іменник | *любода* — любов, *радода* — радість |
| -ар | той, хто робить | *зарьар* — мовець, *писар* — письменник |
| -ик | зменшувальне | *мыркик* — кошеня |
| -иш | місце | *учиш* — школа, *спиш* — спальня |
| -ав | прикметник з іменника | *свѣтав* — світлий |
| -ши | прислівник | *бырзши* — швидко |
| жа- | заперечення, протилежність | *жапомнѫн* — забувати |
| ѳо- | завершена дія | *ѳовидѫн* — побачити |
